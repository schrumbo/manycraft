The second step of the new interface: a real title bar, scrolling that works, and a calmer Start page. Still a beta: it installs over your Manycraft and keeps your data.

- Own title bar on every system: no Windows frame above the app any more, own window buttons with Snap Layouts on the maximise button; macOS traffic lights sit in the bar; on Linux the app draws its buttons, or uses your desktop's frame with "Fensterrahmen vom System"
- Scrolling works again in every list: adding mods, resource packs, shaders and data packs to an instance, Entdecken and Modpacks
- "Inhalte hinzufügen" replaces "Mods hinzufügen" on an instance and no longer offers modpacks, which always become their own instance
- Resource packs and shaders have their own tabs on the instance page: turn them on and off, remove with undo; without a shader loader the Shader tab says which one to add
- Start page reworked: one clear button to continue playing, recently played, batches only when you have some, and "Schnell spielen" for plain Minecraft in any version
- The instance library has room between its cards
- Single instances start without the companion unless you turn on "Companion verwenden" in the instance's settings; batches always use it, and an account with a proxy always takes it along
- Chat shows symbols, other scripts and emoji instead of boxes; server icons that need the server's resource pack are left out
- New app icon
