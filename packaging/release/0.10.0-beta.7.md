Connection-only accounts, a new look, better hover and complete translations. Still a beta: it installs over your Manycraft and keeps your data.

- Batches can run "Nur Verbindung" (Beta): accounts stay on a server without starting the game, at about 1 MB of memory each, with chat, server rules to accept and Wiederbeleben by hand; for Minecraft 26.3, without proxy for now. Whether a server allows it is your call
- A batch can also run as "Verstecktes Spiel": real games without windows, with optional screenshots and a set answer to resource packs
- New Manycraft theme in light and dark, the default unless you picked another one
- Hidden 26.3 games load the world around them again instead of standing in the void
- Restarting a game from the tile or menu always brings it back; connection-only accounts come back after an app update
- Mods, Ressourcenpakete and Shader: the info button (Strg+I) opens the description right next to the list, also for your own files
- Hover follows the pointer in every list, also while scrolling; unread and attention dots stay on their item when the sidebar is folded
- English is complete; dates and times follow the chosen language
- Confirm dialogs keep the keyboard inside them; very long logs no longer keep the window busy
