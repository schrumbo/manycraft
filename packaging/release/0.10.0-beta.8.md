Shared settings, Headless upgrades, real progress and a lighter launcher while you play. Still a beta: it installs over your Manycraft and keeps your data.

- Instances can share options.txt, config/ and the server list, each on its own; new instances share by default, existing ones join with one click. A game that starts with a fresh default file never replaces the shared one, and earlier states can be restored
- "Nur Verbindung" is now "Headless": pick it directly when creating a batch, no instance needed. Resource packs are accepted, and accounts reconnect on their own after drops and server restarts, except when banned
- Headless accounts send the server address the way the game does, which ends "Invalid hostname" kicks behind SRV records; "NBT nested too deep" and other unreadable packets no longer end the connection
- Headless screenshots: what the account sees, drawn with the game's own textures, plus a map from above
- The batch sheet is remade like instance creation; memory is typed in MB with limits; the chat target lists Alle, the batch and its online accounts; the chat sidebar can be resized; the Batches page no longer shows recently played instances
- While you play, the launcher steps aside and comes back when the game closes (Einstellungen › Beim Spielen), using far less memory and graphics memory meanwhile
- Real progress with steps and time left for installs, imports, pack downloads, updates and sign-in instead of spinners
- Garderobe: switching accounts no longer locks the page, skins change in the background, and a visible delete button with undo
- Batches have their own block in the sidebar; instances you play yourself start without the companion mod
