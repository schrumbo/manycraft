Ready for the new interface: the 0.10 beta can now be tried and left again safely.

- With "Vorabversionen" switched on in Settings, Manycraft offers the 0.10 beta like any update and installs it when you quit; with it off, a beta is never offered or installed
- A beta you went back from is not offered again, and neither are older betas
- Going back from the beta keeps everything only the beta knows (themes, launcher defaults, an instance's own default account and memory), so it is all there again when you return
- Instance folders get readable names (instances/Technik instead of a code); existing folders are renamed once, logged and reversible
- To go back to 0.9.3, use "Zu Version zurückkehren" in Manycraft: it restores the old folder names first. Installing 0.9.3 by hand over 0.9.4 would hide your instances
