A new look, a smarter grid and updates that install themselves.

- Mosaic grid: tiles sit edge to edge and fill the window (2 side by side, 3 as two plus one, 4 as quarters), and accounts that need you come first
- Every account has a colour and its face: on the tile, in the game window's title and icon, as a tinted window border on Windows 11 and as a small name badge in the game
- New navy and aqua theme with a new app icon
- Per batch, choose how much a hidden game is slowed down: Economical, Balanced or Full power
- Mod browser searches as you type, shows popular mods first, installs dependencies and undoes removals
- Automatic updates: downloaded in the background, checked against a signature, installed on restart, with a way back to the previous version
- Microsoft sign-in: fix for "invalid_grant" after entering the code
- Code of conduct: Manycraft never plays for you; server rules are your responsibility

Updates from 0.5.0 need one manual install of this version. From here on Manycraft updates itself.
