A full launcher: instances you can play alone, every loader, and a manager that survives anything.

- Instances: version, loader and mods live in an instance; play it alone with one account or start a batch with it, and switch a batch's instance any time
- Vanilla, Fabric, Quilt, Forge and NeoForge install and start from the app; snapshots and old versions down to 1.8.9; your own Java and game options under Erweitert
- Content browser with tabs for mods, resource packs, shaders, data packs and modpacks; a modpack becomes a new instance
- Mods tab: turn mods on and off with dependency checks, your own jars, duplicates, multi-select, updates with changelogs, and a troubleshooter that finds the broken mod
- Worlds with backup and restore, a screenshot gallery, live logs with search, crash reasons, and an mclo.gs upload on request; tokens and personal paths are hidden
- Rename, clone, reset and update instances; delete, reset and most changes can be undone with Ctrl+Z
- Import instances from Prism, MultiMC, Modrinth App, CurseForge, ATLauncher, GDLauncher and the vanilla launcher; desktop shortcuts start an instance directly
- Restarting or a crash of Manycraft brings running games back without relaunching them
- Saves survive a crash mid-write; a damaged file comes back from its backup and Manycraft says so
- Works offline with downloaded instances and reconnects by itself when the network returns
- Large batches start staggered so the computer stays usable; Microsoft sign-ins back off when throttled
- Phone notifications through Discord, Telegram or ntfy when accounts disconnect
- Faster: hidden games use less CPU (Sodium on Fabric and Quilt, audio paused while hidden), the first install reuses files from the official launcher, and the grid scrolls smoothly with 200 games
- The window opens where you left it, on the same screen and page
