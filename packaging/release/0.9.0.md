Your games keep running, whatever happens to the window.

- One companion for every loader: from Minecraft 26.1 a small Java agent replaces the per-loader mod on Vanilla, Fabric, Quilt, Forge and NeoForge; hidden games use about 2-3 % of a core and about 1 GB of memory
- Closing the window or restarting for an update keeps your games running: Manycraft moves to the tray (Dock on macOS) and picks them up again; quitting asks whether they should keep running
- Starting many games only starts what fits in free memory, shows "Startet 12/50" with Cancel, and offers "Trotzdem alle starten"
- Every disconnect shows its reason on the tile, with a history on Space; problems are counted by kind with one fix each; a server outage gets one line and "Jetzt alle verbinden"
- Snapshots before risky instance changes with one undo, a trash that keeps things for 7 days, and "Dort beenden und hier starten" for an account playing elsewhere
- First start to playing in three to four steps; paste a list of offline names; batches start right after creating them
- Stopping everything can be undone; the command palette never preselects a mass action
- Previews refresh faster for the tile under the pointer and pause while nothing is visible
- Your own memory figure per batch, a shortcut overview (Ctrl+/), an ntfy QR code, and notifications that open the right tile
- Proxied games only connect through their proxy; versions before 26.1 run as plain games
