More launcher, less hassle: change something once and the whole batch follows.

- Every game in a batch is master: keybinds, video, sound, resource packs, shader packs and the server list changed in one game apply to all of them; hidden games pick changes up without losing their background savings
- Import Modrinth modpacks (.mrpack) and Prism exports by file or drag and drop; export a batch as .mrpack
- Open the batch folder or a game's folder to drop configs in
- Change skin and cape of Microsoft accounts, with recently used skins
- Keep the computer awake while games run (on by default, the screen may still turn off)
- Microsoft sign-in in its own clean window: add any account, many in a row
- Playing: a maximized game hands back to the grid in one step; games launch hidden at the window's place and resize unseen
- Background: set your own frame rate and render distance for hidden games
- The window draws nothing while idle
- Imported packs that pin an older Fabric Loader start; companion mod also builds for NeoForge and Forge
