A public preview of Manycraft's new interface, rebuilt from the ground up. It is a beta: use it to try the new look and tell us what feels wrong. Keep Manycraft 0.9 for anything that matters.

### It lives next to your Manycraft 0.9

The beta has its own name, its own install folder and its own data folder (`Manycraft Beta`, next to `Manycraft`), and its own entry in the system keychain. It never reads, changes or migrates anything of your 0.9 install, and 0.9 never sees the beta. You can have both installed and open at the same time.

The flip side: **the beta starts empty.** Add your accounts again and create or import your instances in it. Deleting the beta, its folder or its keychain entries leaves 0.9 untouched.

0.9 does not offer this beta as an update. With "Vorabversionen" switched on, 0.9 only shows a link to this page and cannot install it. The beta checks for newer betas on its own (daily, in the background) and installs them like 0.9 installs updates.

### What is new

- A new interface on every system: calmer, faster, built around the keyboard as much as the mouse. Ctrl+K (Cmd+K on macOS) opens the command palette: every action, every instance, batch and account is in it.
- Playing one game is a normal launcher: a game started on its own opens as an ordinary Minecraft window. Only batches use the grid of live previews. Each instance can have its own default account; without one, the active account plays.
- The grid groups instances by batch with sticky headers, stops and starts a whole batch at once, and says why a tile needs attention.
- A redesigned chat: lines look like in the game, write to all accounts at once or pick the sending account quickly.
- Modpacks and mods have their own pages, with description, gallery, versions and dependencies; adds can be undone.
- A trash for deleted batches and instances, undo for the actions that can be taken back, `.mrpack` export for instances and batches.
- Launcher-wide defaults for memory, Java, window and graphics card that instances inherit; themes you can switch and write yourself as JSON in the `themes` folder of the data folder.

### What is unfinished

- It is a preview: expect rough edges, missing polish and the occasional wrong word. Both German and English are included.
- It has had far less use than 0.9. Treat worlds you care about like you would with any beta: keep your own backups.
- The macOS and Linux builds come out of the same pipeline as Windows but have seen less hands-on testing. Linux ships as an AppImage only, no `.deb`, so it cannot replace a package-installed Manycraft.

### Install

- Windows: run `Manycraft-Setup-0.10.0-beta.1-windows-x64-beta.exe`.
- macOS: open `Manycraft-0.10.0-beta.1-macos-universal-beta.dmg` and drag Manycraft Beta to Applications.
- Linux: make `Manycraft-0.10.0-beta.1-linux-x86_64-beta.AppImage` executable and run it.

Every file has a `.sha256` and a `.minisig` signature next to it.

### Send feedback

Open an issue at https://github.com/schrumbo/manycraft/issues. Say which system you are on, what you did, what you expected and what happened; a screenshot helps. Logs are in the `logs` folder of `Manycraft Beta` in your local data folder. Remove account names from anything you paste.
