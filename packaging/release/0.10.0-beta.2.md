A public preview of Manycraft's new interface, rebuilt from the ground up. It is a beta: use it to try the new look and tell us what feels wrong.

### It updates your Manycraft

This beta is no longer a separate app. It installs over your Manycraft 0.9 and becomes your Manycraft: same install folder, same data folder, same keychain entries. Your accounts, instances, batches, worlds and settings are simply there.

- **From Manycraft 0.9.4:** switch on "Vorabversionen" in Settings. Manycraft offers this beta like any update, downloads it and installs it when you quit. While you run a beta it keeps following newer betas, and moves on to 0.10.0 when it comes out.
- **By hand:** run the installer below over your installed Manycraft. A fresh install works too; it is simply Manycraft.

### Your data is backed up first

Before the beta first starts on your data, it copies your accounts, instances, batches and settings (the JSON files, not worlds) into `backup-before-0.10.0-beta.2` in the data folder (`%LOCALAPPDATA%\Manycraft` on Windows, `~/Library/Application Support/Manycraft` on macOS, `~/.local/share/Manycraft` on Linux). The beta only adds new settings to these files and never changes them in a way 0.9 cannot read.

### Going back to 0.9

- **Updated from inside Manycraft:** open Settings › Updates and click "Zurückkehren" next to "Vorherige Version". Manycraft puts 0.9.4 back and does not offer this beta again.
- **Installed by hand:** download `Manycraft-Setup-0.9.4-windows-x64.exe` (or the 0.9.4 `.dmg` / `.AppImage`) from the 0.9.4 release and install it over the beta. Switch off "Vorabversionen" if you do not want the next beta offered.

0.9.4 keeps all your accounts, instances, batches and settings, and keeps what only the beta knows (themes, launcher defaults, per-instance default accounts) in the files, so it is there again when you return to the beta. Batches in the beta's trash stay hidden in 0.9.

### Coming from beta.1

beta.1 was a separate app called "Manycraft Beta" and cannot update itself to this version. Uninstall "Manycraft Beta", install this beta by hand and add your accounts again. Its data folder `Manycraft Beta` is not read; delete it when you no longer need it.

### What is new

- A new interface on every system: calmer, faster, built around the keyboard as much as the mouse. Ctrl+K (Cmd+K on macOS) opens the command palette: every action, every instance, batch and account is in it.
- Playing one game is a normal launcher: a game started on its own opens as an ordinary Minecraft window. Only batches use the grid of live previews. Each instance can have its own default account; without one, the active account plays.
- The grid groups instances by batch with sticky headers, stops and starts a whole batch at once, and says why a tile needs attention.
- A redesigned chat: lines look like in the game, write to all accounts at once or pick the sending account quickly.
- Modpacks and mods have their own pages, with description, gallery, versions and dependencies; adds can be undone.
- A trash for deleted batches and instances, undo for the actions that can be taken back, `.mrpack` export for instances and batches.
- Launcher-wide defaults for memory, Java, window and graphics card that instances inherit; themes you can switch and write yourself as JSON in the `themes` folder of the data folder.

### What is unfinished

- It is a preview: expect rough edges, missing polish and the occasional wrong word. Both German and English are included.
- It has had far less use than 0.9. Treat worlds you care about like you would with any beta: keep your own backups.
- The macOS and Linux builds come out of the same pipeline as Windows but have seen less hands-on testing. Linux ships as an AppImage only, no `.deb`, so it cannot replace a package-installed Manycraft.

### Install

- Windows: run `Manycraft-Setup-0.10.0-beta.2-windows-x64.exe`.
- macOS: open `Manycraft-0.10.0-beta.2-macos-universal.dmg` and drag Manycraft to Applications, replacing the one there.
- Linux: make `Manycraft-0.10.0-beta.2-linux-x86_64.AppImage` executable and run it in place of your current one.

Every file has a `.sha256` and a `.minisig` signature next to it.

### Send feedback

Open an issue at https://github.com/schrumbo/manycraft/issues. Say which system you are on, what you did, what you expected and what happened; a screenshot helps. Logs are in the `logs` folder of the data folder. Remove account names from anything you paste.
