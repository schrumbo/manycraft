A new layout and many new pages. Still a beta: it installs over your Manycraft and keeps your data.

- New navigation: Start, Instanzen, Entdecken, Garderobe, Batches and Einstellungen, with every page using the full window width
- Garderobe: a skin library per account; wear a skin with one click, pick a cape, add skins by link, player name, file or drag and drop
- Creating an instance fits on one page: name, version, loader, memory, and an optional performance preset of 15 tested mods; modpacks can be searched right there, .mrpack files can be dropped in
- The batch chat is now a sidebar you can open beside the games, with an unread dot; the batch toolbar opens the batch settings directly
- Mods, Ressourcenpakete and Shader: wide lists with big icons, a quiet update check with "Alle aktualisieren", and an info page per project with its description and links
- Logs: select text and copy it. Welten: one list with actions per world. Screenshots: a viewer with zoom, arrow keys and "Bild kopieren"
- The Manycraft window keeps its size and maximized state when you switch back from a game
- macOS: switching to a game brings it to the front reliably
