First public preview: one window for many Minecraft Java accounts.

- Grid of live previews; a tile swaps the real game window into the manager's place, a hotkey brings the grid back
- Batches with Fabric, Modrinth mods and mod updates; several batches side by side
- Microsoft and offline accounts, a proxy per account
- Auto-reconnect with polite backoff, ban detection, crash restart, drop reasons on every tile
- Merged chat with whisper alerts and broadcast to a batch
- Prism Launcher import for accounts and instances
- Multi-select with bulk actions, command palette (Ctrl+K)
- Hidden instances run a minimal background profile

Not yet verified on real macOS and Linux desktops, and Microsoft sign-in has not been tested end to end. Feedback welcome in Issues.
