- One play button everywhere (instance page, Start, library cards) that always tells the truth: Spielen, Startet …, Zum Spiel with a stop button, Stoppt … and after 10 seconds Sofort beenden, Wird installiert with progress, Anmelden als, and Erneut spielen after a crash
- After a crash the instance shows "Abgestürzt" with the likely reason and a way to the log
- A running game shows how long it has been running and how much memory it uses
- Ctrl/Cmd+Enter plays, Ctrl/Cmd+. stops
- Chat now sits with the batches in the sidebar and counts unread lines
- The batch sheet has "Schneller beim Spielen (mehr Arbeitsspeicher)" again
- Minimise, maximise and Schnell spielen are in the command palette with shortcuts
- The search field in the title bar shrinks in narrow windows instead of covering the path
- The window shows the new app icon in the taskbar and Alt+Tab
